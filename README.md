# 🏢 Agency & Job Portal UI

A multi-page front-end template built with HTML and CSS. This project features a corporate landing page, a job listing board, and a modern login page using glassmorphism effects.

## ⚡ Project Overview

This project focuses on creating a clean, structured multi-page layout. It demonstrates the use of custom CSS styling for tables, navigation bars, and visually appealing authentication forms without relying on any external frameworks.

## 🧰 Key Features

*   **Glassmorphism Login Form:** A premium-looking login card utilizing CSS `backdrop-filter: blur()` and transparent backgrounds.
*   **Custom Data Table:** A styled and structured job board (Careers page) showcasing positions, experience, and required skills.
*   **Multi-Page Navigation:** Separate interconnected HTML pages (Home, Careers, Login) with a consistent navigation bar.
*   **Hover Animations:** Smooth CSS transitions on navigation links, buttons, and table rows for better user interaction.

## 📁 File Structure

- `index.html` - Landing page with hero banner.
- `career.html` - Job listings page featuring a custom CSS data table.
- `login.html` - Authentication page with a glassmorphism card.
- `style.css` - Global stylesheet containing all layout rules and visual effects.
